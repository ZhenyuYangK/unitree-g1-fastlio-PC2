# 网页建图

PC2 / Foxy 源码已接入现有 `g1_mapping.sh`。网页管理雷达与 FAST-LIO 的启动、保存、结束和停止，不发送机器人行走、姿态或任务执行指令。

## 使用步骤

1. 如果定位/Nav2 或运动桥已经运行，先按原管理方式结束这些进程。建图页会显示互斥原因，不自动关闭现有业务。
2. 启动 ROS 网关，以便同时接收点云预览：

```bash
cd "$G1_WS"
read -rs -p "网页访问口令: " G1_WEB_TOKEN
export G1_WEB_TOKEN
G1_WEB_HOST=0.0.0.0 G1_WEB_MODE=ros_readonly bash web_console/run.sh
```

3. 打开 `http://电脑的可达IP:8080`，登录，点击“取得操作权”，进入“建图管理”。
4. 填写地图名称（可留空；支持汉字、字母、数字、下划线、短横线），点击“开始建图”。等最近操作显示完成、雷达与 FAST-LIO 均运行后，用遥控器带机器人采集环境。
5. 点云俯视预览展示 `/cloud_registered` 的 XY 投影、坐标系、采样次数和最近一帧点数。超过 3 秒无数据会标记过期。
6. 按需选择：

| 按钮 | 行为 |
| --- | --- |
| 保存地图 | 请求 `/map_save` 并确认新 PCD 有效，继续采集 |
| 保存并结束建图 | 先确认保存成功，再结束进程；保存失败时保留采集进程 |
| 停止建图 | 不主动请求保存，停止已核实归属的建图进程；底层节点退出时的写盘行为由 FAST-LIO 决定 |
| 下载 PCD 地图 | 下载当前会话最近保存的有效点云 |

网页默认禁用 RViz，方便无图形会话操作；CLI 原有的 RViz 配置保持可用。`local` 模式也可管理建图，但没有 ROS 点云订阅，预览会提示切换到 ROS 模式。`mock` 模式不执行建图操作。

## 成果与地图边界

新成果保存在 `maps/web_maps/<名称>_<会话编号>.pcd`，不覆盖 `map.pcd`、现有 PGM/YAML、导航点或巡航任务。

点云俯视图用于观察采集覆盖，不是导航栅格图，也不是可通行性判定。网关对点云按空间采样、限帧与限量，完整成果由 FAST-LIO 保存。新地图的二维转换继续使用现有 `maps/pcd2pgm_multilayer.py`；本次没有接入网页栅格转换或导航地图切换。使用新地图导航前，应核对 PCD/PGM/YAML 的对应关系，并重新核对或采集导航点。

## 状态与失败处理

- 操作立即返回 HTTP 202，由后台执行。页面每 0.5 秒同步阶段、进程与执行结果；202 不代表已启动或已保存。
- “最近操作”显示已接受、执行中、已完成、未成功或结果未确认；日志包含操作、雷达和 FAST-LIO 的最近输出。
- 浏览器断线、租约到期或关闭页面不会取消已接受的建图操作。重新连接后先查看当前会话，不自动重发命令。
- 网关退出不自动停止已经分离启动的雷达/建图进程。进行中的包装命令被中断时标记结果未确认；重启网关后根据持久记录和实际进程恢复显示。
- 保存必须满足服务 `success=true`、目标文件确实更新、PCD 非空且数据完整。服务拒绝、旧文件未变或文件不完整均不报告成功。
- “保存并结束”失败时先查看日志；如果雷达/FAST-LIO 仍在运行，可修复后重新保存或明确停止。
- PID 使用 P1 JSON 归属记录，包含 boot ID、创建时间、命令行哈希及启动 token，停止前核对进程组，结束后确认退出。旧版本无启动标识的 PID 记录会显示归属未确认，不自动向可能复用的 PID 发信号。需要在现场核对记录和 `ps` 命令行，手动结束确认为原会话的进程后，再建立新会话。
- 建图、定位导航启动/停止共用生命周期锁；任务运行和停止恢复标记阻止建图启动。建图期间禁止网页修改导航配置。

运行状态与产物记录位于 `runtime/mapping/`，网页操作记录位于其 `web/` 子目录。命令固定为服务端脚本的 start/save/finish/stop，不接受浏览器传入 shell、文件路径、ROS 参数或任意程序。

## 验证记录与现场验收

自动化使用临时工作空间、测试自建进程和隔离 DDS，未启动真实机器人建图：

- 网关协议、异步结果、重复请求、进程/任务互斥、失败保留、PCD 下载、PID 归属和退出确认。
- 浏览器启动/保存/保存失败/保存并结束/停止、第二页面同步、刷新、断线恢复、手机布局、主题与键盘焦点。
- 隔离 ROS Domain / 回环接口接收实际 PointCloud2 消息，校验保存服务成功和拒绝响应；只写临时 PCD。

```bash
PYTHONPATH=web_console/backend web_console/.venv/bin/python -m unittest discover -s web_console/tests -v
# 已安装 Playwright 与 Chrome 时，自包含浏览器测试，不需要另起真实网关：
PYTHONPATH=web_console/backend web_console/.venv/bin/python web_console/tests/browser_mapping_smoke.py
```

现场依次验收：导航已结束 → 从网页启动 → 点云持续更新 → 采集一小块区域 → 保存并下载 → 核对 PCD 可读 → 再次采集后保存并结束 → 确认进程退出。记录日志、文件大小和实际采集情况。上述现场流程尚未由自动测试代替。
