# 公共导视牌视觉规范

遵循用户指定的机场 / 博物馆导视风格：一个主要识别元素为深蓝站点横幅，其余区域保持安静、清楚。

## 色彩

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | #eef1f5 | #0b1730 |
| 卡片 | #ffffff | #12264b |
| 边框 | #d5dce7 | #264070 |
| 导视横幅 | #12294a | #06101f |
| 正文 | #14213a | #e8eefb |
| 次要文字 | #5d6b82 | #a7b7d4 |
| 当前动作 / 编号 / 主按钮 | #f2c230 | #f2c230 |
| 地图房间 | #dfe6f0 | #1b3357 |
| 地图轮廓 | #b9c5d6 | #385581 |
| 路线 | #2f6bff | #6fa0ff |
| 完成站点 | #1f9d63 | #3ccf8e |
| 紧急停止 | #d23a2f | #ff6b5e |

红色保留用于明确的紧急停止已触发状态。取消任务为中性色按钮；一般错误用黄色提示，不使用红色。

## 字体与形状

- Barlow 用于正文与按钮，Barlow Condensed Bold 用于站名和站号，数字采用 tabular-nums，不使用等宽字体。
- 字体随项目离线提供，保留各自 SIL OFL 授权文件。Barlow 不含中文字形，中文采用系统无衬线字体回退。
- 站名约 2rem、粗体；地图、横幅、站点列表和导航点目录使用一致的“深蓝底牌 + 黄色编号圆形”标记。
- 完成站点编号圆形转为绿色；当前站点行采用浅黄色背景，并有文字状态，不只依赖颜色。
- 卡片圆角 12px、细边框、无阴影。按钮圆角 10px，主要动作按钮为最大的黄色按钮。
- 导视横幅有 6px 黄色下边缘；只有收到明确的 emergency_stop.active=true 才显示红色下边缘。
- 网页已移除未接入的紧急停止占位按钮及说明；普通任务取消保留原有语义。

## 交互

- 支持浅色 / 深色切换，首次跟随设备偏好，手动选择保存在当前浏览器。
- 无渐变、阴影、装饰动画；仅机器人位姿和进度条使用过渡，prefers-reduced-motion 下禁用。
- 所有可操作控件具有明显的键盘焦点，导航包含 aria-current，进度条包含数值语义。
- 英文使用 sentence case，按钮以动作动词描述行为。
- 手机布局保留站点横幅、控制权限和状态新鲜度，不出现页面横向溢出。
- 顶部与操作设备卡片显示“操作剩余时间：分:秒”；状态过期时显示“待同步”，本设备凭证待确认时显示“核验中”。

字体来源：[Barlow](https://github.com/google/fonts/tree/main/ofl/barlow)、[Barlow Condensed](https://github.com/google/fonts/tree/main/ofl/barlowcondensed)。
